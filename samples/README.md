# samples/

Small, **curated** example data and configurations for development, tests and
documentation: example region queries, route/mission definitions and tiny result
fixtures.

Keep it small and intentional:

- ✅ tiny, representative fixtures committed on purpose.
- ❌ no bulk catalog dumps or large downloads — UNAV-SA never relies on full
  survey mirrors (see [`docs/DATA_SOURCE_STRATEGY.md`](../docs/DATA_SOURCE_STRATEGY.md)).

Empty for now — populated as features land.
