# adapters/houdini/

Houdini adapter for UNAV-SA. **Future work — not implemented yet.**

A thin client that consumes UNAV-SA interchange / local API and maps results
into Houdini. No astronomy logic and no heavy scientific dependencies inside the
Houdini runtime. Comes *after* the Cinema 4D adapter.

See [`docs/DCC_ADAPTER_STRATEGY.md`](../../docs/DCC_ADAPTER_STRATEGY.md).
