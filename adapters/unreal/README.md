# adapters/unreal/

Unreal Engine adapter for UNAV-SA. **Future work — not implemented yet.**

A thin client that consumes UNAV-SA interchange / local API and maps results
into Unreal. No astronomy logic and no heavy scientific dependencies inside the
Unreal runtime. Comes *after* the Cinema 4D adapter.

See [`docs/DCC_ADAPTER_STRATEGY.md`](../../docs/DCC_ADAPTER_STRATEGY.md).
