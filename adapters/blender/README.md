# adapters/blender/

Blender adapter for UNAV-SA. **Future work — not implemented yet.**

A thin client that consumes UNAV-SA interchange / local API and maps results
into Blender. No astronomy logic and no heavy scientific dependencies inside the
Blender runtime. Comes *after* the Cinema 4D adapter.
